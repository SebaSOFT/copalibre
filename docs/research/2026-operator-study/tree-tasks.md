# Tree-test tasks / Tareas para la prueba del árbol

Read one prompt at a time. Do not show the moderator-only expected destinations to participants.
Accept the participant's first destination before asking a neutral follow-up question. Do not teach or
explain the tree during the test.

Lee una consigna por vez. No muestres a los participantes los destinos esperados, que son solo para
la persona moderadora. Registra el primer destino antes de hacer una pregunta neutral. No enseñes ni
expliques el árbol durante la prueba.

## English

### Task 1 — Change a match venue

A scheduled match cannot use its current venue. Where would you go to change the venue?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Schedule`

### Task 2 — Confirm cup qualifiers

The group stage has finished. Where would you confirm which teams advance to the cups?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Seeding and brackets > Qualification confirmation`

### Task 3 — Pair a television screen

A new television screen should show this tournament. Where would you go to pair it?

- Expected destination (English): `Organization > Dashboard > TV devices`

### Task 4 — Invite a tournament referee

A referee should have access to this tournament only. Where would you invite them?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Officials`

### Task 5 — Correct a result

A match result was entered incorrectly. Where would you go to start correcting it?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Schedule`

### Task 6 — Understand a tie

Two teams have the same points. Where would you look to understand why they are tied?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Zones and groups > Group standings`

### Task 7 — Export participants

An organizer needs a file containing participant information. Where would you go to export it?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Teams and rosters`

### Task 8 — Set a rest interval

An organizer wants at least 120 minutes between an entrant's matches. Where would you set that?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Overview > Tournament settings > Scheduling`

### Task 9 — Hide a public profile

A player asks not to appear on public pages. Where would you go to apply that choice?

- Expected destination (English): `Organization > Tournaments > Tournament list > Panamericano > Teams and rosters`

### Task 10 — Find changes by one person

The league director wants to find yesterday's changes made by one official. Where would you look?

- Expected destination (English): `Organization > Audit trail`
