# Security Policy

## Supported versions

The latest release line is supported for security fixes. Upgrade to the latest release before
reporting a vulnerability in an older line.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/SebaSOFT/copalibre/security/advisories/new).
Do not disclose vulnerabilities in public issues, pull requests or discussions.

Include the affected release or commit, the impact, reproduction steps and any relevant environment
details. Avoid attaching credentials, tokens or real personal data.

Maintainers read and handle private reports. No response or fix time is promised.
