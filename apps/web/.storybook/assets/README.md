# TV preview scenes

`football-field.webp` and `basketball-court.webp` are generated illustrative venue images created for
CopaLibre's local Storybook workbench on 2026-09-09. They depict no identified venue or event. Both
were generated with OpenAI's image-generation tool, then encoded as WebP at quality 80.

- Football: an elevated broadcast view of an empty community pitch in bright daylight.
- Basketball: an elevated sideline view of an empty indoor court with darker arena seating.

These decorative samples test overlay readability against different footage conditions. They do not
select a discipline, represent tournament data, or ship as production TV backgrounds. Imports from
the Storybook preview keep them local and independent of remote image hosts.
