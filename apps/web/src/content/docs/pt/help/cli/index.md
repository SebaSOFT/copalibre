O CLI `copalibre` opera uma instalação autohospedada: instala, valida a configuração, inicia os
processos, gerencia módulos e faz backup/restauração de dados. Toda invocação aceita `--help`/`-h` —
tanto sem comando (`copalibre --help`) quanto após qualquer comando (`copalibre doctor --help`) —
para mostrar seu uso exato sem executar nenhum efeito real.
