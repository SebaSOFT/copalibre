A autoridade de cada função vem de uma única correspondência declarada, não da leitura de cada tela e
rota que a menciona. Esta seção tem uma página por função, cada uma informando o que essa função pode
fazer (gerado diretamente a partir da correspondência, para que nunca possa se desviar silenciosamente
do que é realmente aplicado), o que herda e de qual função, o que notavelmente não pode fazer, e quais
telas do painel de controle ela vê.

- [Admin](/pt/help/roles/admin/)
- [Admin de clube](/pt/help/roles/club-admin/)
- [Admin de torneio](/pt/help/roles/tournament-admin/)
- [Árbitro](/pt/help/roles/referee/)
- [Transmissão](/pt/help/roles/broadcaster/)
- [Viewer](/pt/help/roles/viewer/)
- [Super-admin](/pt/help/roles/super-admin/)

Admin, admin de clube, admin de torneio, árbitro, transmissão e viewer são funções de organização —
mantidas dentro de uma organização, sem sentido fora dela. Super-admin é diferente: uma função no nível
da instalação, um nível acima de cada organização, descrita em sua própria página.
