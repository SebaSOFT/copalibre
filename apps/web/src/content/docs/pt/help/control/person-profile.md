## Para que serve esta tela

Mostra a identidade de uma pessoa registrada: sua foto (ou um placeholder quando nenhuma foi enviada),
nome de exibição, bandeira de nacionalidade e chave natural — o mesmo número de documento usado para
reconhecê-la entre equipes e competições. Acessada por "Ver perfil" a partir da linha expandida da tela
de revisão de inscrições.

## Campos principais

- **Foto**: exibida quando uma foi enviada pela tela de revisão de inscrições; caso contrário, uma
  silhueta placeholder é exibida no lugar, nunca uma imagem quebrada.
- **Nacionalidade**: a bandeira do código de país ISO 3166-1 alpha-2 registrado para a pessoa, quando
  definido.
- **Chave natural**: o documento identificador (por exemplo, um número de identidade nacional)
  registrado para essa pessoa, quando existir.

## O que esta tela NÃO faz

Ela não permite editar nada — nacionalidade e foto são definidas a partir da linha expandida da tela
de revisão de inscrições, não aqui. Não existe uma tela separada de "editar pessoa".
