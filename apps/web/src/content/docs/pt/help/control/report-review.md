---

## Para que serve esta tela

Mostra os relatórios e disputas que os próprios participantes enviaram sobre uma partida (por
exemplo, "o resultado registrado não é o que jogamos", com evidências anexadas) para que um
organizador os revise e decida o que fazer.

## Campos principais

- **Relatório** vs. **disputa**: um relatório é uma afirmação do participante sobre o que aconteceu;
  uma disputa questiona especificamente um resultado já registrado.
- **Evidência**: anexos (imagem, vídeo, PDF) que o participante enviou como apoio. Eles passam por
  uma verificação assíncrona de conteúdo/malware antes de contar como válidos — um anexo marcado
  como não seguro nunca é mostrado como válido a nenhum revisor.
- **Status de revisão**: pendente, revisado ou descartado, com uma nota do revisor.

## O que esta tela NÃO faz

Revisar um relatório **nunca** sobrescreve um resultado diretamente. Um resultado já registrado só
muda pelo caminho auditado de correção/substituição (motivo, estado anterior, estado resultante,
prévia de recálculo) — esta tela é onde um organizador decide _se_ essa correção é justificada, não
onde a correção em si acontece.
