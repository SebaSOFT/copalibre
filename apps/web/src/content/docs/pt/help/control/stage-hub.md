## Para que serve esta tela

Mostra o número, nome atual e formato de uma fase, e é onde essa fase é renomeada, tem o formato
alterado, ou é removida. Também linka para o sorteio, zonas e grupos, classificação e calendário
dessa mesma fase, e cada um deles linka de volta para cá.

## Dados principais

- **Renomear**: sempre disponível, tenha a fase sido sorteada ou não.
- **Alterar formato**: disponível apenas enquanto a fase não possuir uma partida gerada. Uma vez
  sorteada, a tela explica por que a ação está bloqueada em vez de apenas recusá-la
  silenciosamente.
- **Excluir fase**: disponível apenas enquanto a fase não possuir uma partida gerada, e apenas
  enquanto nenhum plano de promoção já a tiver como alvo.

## Como chegar a esta tela

Abra-a a partir da lista de fases de um torneio, ou a partir do link de trilha de navegação no
sorteio, zonas e grupos, classificação ou calendário dessa fase.
