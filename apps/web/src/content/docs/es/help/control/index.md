Cada pantalla del panel de control tiene un enlace "¿Qué es esta pantalla?" en su barra lateral que
lleva directamente a la página correspondiente de esta sección. Esta página las lista todas.

- [Creación de torneo](/es/help/control/tournament-authoring/)
- [Revisión de inscripciones](/es/help/control/registration-review/)
- [Revisión de reportes y disputas](/es/help/control/report-review/)
- [Posiciones (standings)](/es/help/control/standings/)
- [Sorteo y siembra (seeding)](/es/help/control/seeding/)
- [Roles y permisos](/es/help/control/roles-permissions/)
- [Consola de partido en vivo](/es/help/control/match-console/)

Para instalar, actualizar o entender los comandos del CLI de administración, vea la
[documentación del CLI](/es/help/cli/).
