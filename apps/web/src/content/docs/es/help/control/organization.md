# Organización

## Para qué sirve esta pantalla

Permite a los administradores gestionar la configuración de la organización y el uso de almacenamiento multimedia.

## Cuota de almacenamiento

Muestra el espacio utilizado en emblemas, retratos y archivos adjuntos.
