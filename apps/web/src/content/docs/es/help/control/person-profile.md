---
title: Perfil de la persona
description: La foto, nombre, nacionalidad y documento de una persona, accesible desde la revisión de inscripciones.
---

## Para qué sirve esta pantalla

Muestra la identidad de una persona inscrita: su foto (o un marcador de posición cuando no se subió
ninguna), nombre para mostrar, bandera de nacionalidad y documento — el mismo número usado para
reconocerla entre equipos y competiciones. Se accede con "Ver perfil" desde la fila expandida de la
revisión de inscripciones.

## Datos clave

- **Foto**: se muestra cuando fue subida desde la pantalla de revisión de inscripciones; en caso
  contrario se muestra una silueta de marcador de posición, nunca una imagen rota.
- **Nacionalidad**: la bandera correspondiente al código de país ISO 3166-1 alfa-2 registrado, cuando
  está definido.
- **Documento**: el documento identificatorio (por ejemplo, un número de identidad nacional)
  registrado para esta persona, cuando existe.

## Qué NO hace esta pantalla

No permite editar nada — la nacionalidad y la foto se definen desde la fila expandida de la revisión
de inscripciones, no aquí. No existe una pantalla separada de "editar persona".
