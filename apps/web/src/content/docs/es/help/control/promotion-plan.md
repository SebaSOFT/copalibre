title: Plan de promoción
description: Configurá cómo se combinan los grupos de una zona en el sembrado de la siguiente etapa — revisado antes de aplicarse.
---

## Para qué sirve esta pantalla

Una vez que los grupos de una zona terminaron su fase de todos contra todos, esta pantalla configura
cuántos entrantes avanzan de cada grupo y cómo se combinan esos grupos en una sola lista ordenada para
la siguiente etapa. Después muestra esa lista ordenada y calculada para revisión — nunca crea ni
modifica ningún sembrado por sí sola.

## Datos clave

- **Entrantes que avanzan por grupo**: cuántos entrantes de cada grupo se promueven.
- **Bandas**: cuando la siguiente etapa tiene más de una zona, qué tramo contiguo de la lista
  combinada se dirige a cuál de las zonas de esa etapa.
- **Revisión**: la lista de candidatos ordenada que este plan promovería, calculada siempre de la
  misma manera — nada se escribe en la siguiente etapa hasta que un operador configure explícitamente
  su sembrado desde el armador de sembrado, que se prellena a partir de un plan revisado cuando existe
  uno.

## Qué no podés hacer acá

Si un grupo tiene un empate sin resolver en su propia línea de corte, esta pantalla lo informa en vez
de presentar una lista incompleta — resolvé el empate (una corrección auditada, si el resultado de
origen necesita una) antes de que se pueda calcular una lista combinada.
