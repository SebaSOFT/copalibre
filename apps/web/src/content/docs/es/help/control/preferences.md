## Para qué sirve esta pantalla

La pantalla de preferencias te permite gestionar tu configuración personal en CopaLibre.

## Tokens de acceso personal

Podés generar tokens de acceso personal (PAT) para autenticarte contra la API o el servidor MCP de
CopaLibre sin usar tu usuario y contraseña.

- **Generar un token**: ingresá una etiqueta y una duración de expiración, y presioná «Generar».
  Asegurate de copiar el token de inmediato, ya que no se puede volver a ver.
- **Revocar un token**: si un token se compromete o ya no se necesita, podés revocarlo en cualquier
  momento.

Estos tokens no tienen estado y verifican tu identidad en cada solicitud.
