# Analytique

## Objectif de cet écran

L’écran Analytique présente les indicateurs clés et les volumes opérationnels de l’organisation.

## Aperçu des tournois

L’aperçu répertorie chaque tournoi non archivé avec son statut, le nombre de matchs résolus sur le total et le nombre de matchs en direct. Si la progression d’un tournoi est indisponible, le reste du tableau de bord reste visible.
