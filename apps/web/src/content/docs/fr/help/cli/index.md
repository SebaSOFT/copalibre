---
title: Le CLI copalibre
description: Installation, mise à jour et référence des commandes du CLI copalibre.
---

Le CLI `copalibre` exploite une installation autohébergée : il installe, valide la configuration,
démarre les processus, gère les modules et sauvegarde/restaure les données. Chaque invocation
accepte `--help`/`-h` — sans commande (`copalibre --help`) et après n'importe quelle commande
(`copalibre doctor --help`) — pour afficher son usage exact sans exécuter aucun effet réel.
