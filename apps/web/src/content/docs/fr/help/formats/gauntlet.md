## Vue d’ensemble

Le format Gauntlet (ou échelle) est un tableau à élimination directe ascendante. Les équipes les moins bien classées s'affrontent en premier, le vainqueur se qualifiant pour défier la tête de série immédiatement supérieure.

## Progression

- **Tour 1** : Tête de série N affronte Tête de série N-1.
- **Tour 2** : Vainqueur du Tour 1 contre Tête de série N-2.
- **Grande Finale** : Le vainqueur de l'échelle affronte la tête de série 1 pour le titre.
