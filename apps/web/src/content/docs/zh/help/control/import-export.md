## 导入

参赛者可从[报名审核](/help/control/registration-review)界面通过 CSV 批量导入。写入任何内容之前，
每一行都会先被校验：未通过校验的行会附带其行号和原因被报告出来，除非整份文件被接受，或被更正后重
新上传，否则不会导入任何一行——部分导入的文件不是此界面会产生的状态。此前从同一安装导出的 CSV 可
以顺利重新导入，因此对参赛者名单做一次往返（在电子表格中编辑后再带回来）是受支持的做法，而不是意
外。

## 导出

- **参赛者**：按别名导出的个人或团队名单——可从[报名审核](/help/control/registration-review)进入。
- **结果与积分榜**：按别名导出的某阶段已计算结果和积分榜——可从[积分榜](/help/control/standings)
  进入。
- **赛事配置**：完整规则集、覆盖项和自定义脚本的 JSON 格式——从组织仪表盘导出，与全新安装可重新导
  入以复现该赛事规则（而非其结果）的文档相同。

每次导出都会用实体的公开别名替换内部数据库标识符，因此导出的文件永远不会泄露任何本不应被安装之外
的人看到的标识符。

## 此界面无法进行的操作

不支持导入结果或积分榜——这些是计算得出的，而非录入的，事后更改它们的唯一方式是
[审计化更正流程](/help/control/corrections)。
