title: 加载比赛数据
description: 为没有实时控制台在场进行的比赛提供批量/结构化录入。
---

## 此界面的用途

并非每场比赛在进行时都有操作员在控制台旁。此界面可让您在赛后一并录入一场比赛的名单、完整事件历史和
最终结果——适用于报告客场比赛的俱乐部，或正在补录一批纸质记分表的组织者。

仅适用于尚无已记录活动的已排定比赛。若比赛已经有来自实时会话的事件或赛段，应改为通过
[实时控制台](/help/control/match-console) 完成——在实时历史之上加载第二份历史会与其产生冲突。

## 关键字段

- **名单**：与实时控制台提供的相同的按参赛方球员选择，仅保留在此界面上直到您提交——在整批数据提交之
  前，不会保存到该场比赛中。
- **赛段**：比赛所拥有的每个节/半场/局，按比赛顺序排列，每个都已标记为已完成并附带其时长。此处没有
  实时计时器。
- **事件**：比赛的完整历史，按其实际发生的顺序排列，每个事件都附有各自的真实时间戳——而非您录入它的
  那一刻。
- **结果**：比赛的最终结果，与上述内容一并提交。

## 一次提交，全部成功或全部失败

按下"提交比赛数据"会将名单、每个事件和结果一并作为一个事务发送。如果任何一个事件无效，则不会记录
任何内容——整个提交会被拒绝，您已录入的内容会保留在界面上，以便您修正失败的那一条记录后重新提交，
而无需从头开始。

## 从电子表格导入

"从 CSV 导入"部分会将电子表格加载到上方的同一编辑器中以供审核——它绝不会跳过审核步骤或提交时的校
验。下载模板以了解文件所需的确切列格式。
