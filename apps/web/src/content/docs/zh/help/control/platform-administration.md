## 此界面的用途

这是安装本身专属的控制台，只能以 `super-admin` 身份访问——比任何组织高一级。此处的任何操作都不局
限于单一组织：每个操作都会影响整个安装。

## 组织

在此创建新组织——其别名、显示名称、主要语言和时区——并在同一步骤中通过邮件邀请其第一位管理员。创建
组织时未邀请管理员，就没有人能登录并管理它，所以两者要一起完成。

## 用户

通过别名可以进入任意组织的用户列表，因此超级管理员无需成为该组织成员即可进入并更改用户的角色或状
态。

## 超级管理员

在此列出、创建和移除安装的超级管理员。超级管理员通过主体 ID 创建——该身份必须已经存在（至少登录过
一次），才能被提升。

## 模块

在此按别名安装项目模块和赛事模板模块，可选版本范围，以及对于默认目录中没有的模块可选的备用来源。
已安装的模块会列出其类型、版本和来源，可以进行校验或移除。检查更新会将已安装版本与每个模块来源当
前发布的版本进行比对，在被要求之前不会安装任何内容。

## 此界面无法进行的操作

此处的任何操作都不会触及某个组织自身的赛事数据——在此界面看不到也无法编辑任何比赛、结果或报名信
息。那是每个组织自己的控制面板，由组织管理员访问，而不是超级管理员通过此控制台操作。
