# 实时控制台

## 此屏幕用途

快速访问正在进行的赛事和实时比赛操作。

## 分段

比赛按分段进行：上半场、下半场、盘或节。「开始比赛」会创建比赛规则规定的常规分段，例如足球比赛的两个半场，或三局两胜制中决出胜负所需的盘数，并启动第一个分段。「暂停」和「结束分段」作用于正在进行的分段。

「添加分段」会追加该项目声明的任一类型的分段，例如加时、点球大战或决胜盘。超出常规计划的分段会被接受，并标注为「（超出计划）」：常规时间之后比赛如何进行由主办方决定。

已开始但没有任何分段的比赛仍可继续操作：在「添加分段」中选择一种类型，然后从新分段继续比赛。
