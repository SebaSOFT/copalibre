## 此界面的用途

显示参赛者就某场比赛提交的举报和争议（例如"已录入的结果与我们实际比赛的情况不符"，并附有证据），以便组织者审核并决定如何处理。

## 关键字段

- **举报**与**争议**：举报是参赛者对所发生情况的陈述；争议则专门针对已录入的结果提出异议。
- **证据**：参赛者上传的支持材料（图片、视频、PDF）。它们需要通过异步的内容/恶意软件检测后才被视为有效——被标记为不安全的附件绝不会向任何审核人员显示为有效。
- **审核状态**：待处理、已审核或已驳回，并附有审核备注。

## 此界面不做的事

审核举报绝不会直接覆盖结果。已录入的结果只能通过经过审计的更正/替代流程（原因、先前状态、结果状态、重新计算预览）来更改——此界面是组织者判断是否需要更正的地方，而不是更正实际发生的地方。
