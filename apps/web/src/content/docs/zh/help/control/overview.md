此面板是单个组织的首页，汇总快捷统计、组织赛事、显示设备状态和近期活动。

## 快捷统计

摘要显示正在进行的赛事、待处理报名，以及安排在今天的比赛。统计范围是控制面板当前选中的组织。

## 赛事

每张赛事卡片提供赛事摘要和通往其操作页面的链接。根据你的权限和赛事状态，卡片操作还可能支持导出赛事数据或配置、管理转播显示令牌，或归档赛事。拥有创建赛事权限的用户可以在此创建赛事。

## 显示设备和近期活动

设备区域显示与组织赛事关联的转播设备连接状态。近期活动区域列出组织中最近记录的操作。
