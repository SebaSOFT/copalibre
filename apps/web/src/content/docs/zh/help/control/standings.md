## 此界面的用途

显示某个赛事阶段的排名表——谁排在哪里、为什么，并可查看计算过程的解释，而不仅仅是最终数字。

## 关键字段

- **阶段**：赛事的一个阶段（例如"小组赛"或"淘汰赛"），拥有自己的赛制和自己的排名表。一项赛事可以有多个串联的阶段。
- **积分/标准**：计分和决胜标准由该项目所声明的规则决定——此界面绝不会自行发明标准，只会应用并展示计算时所生效配置对应的标准。
- **可解释性**：每个名次都可以展开查看，究竟是哪些数据和哪条规则决定了该名次——是产生这个数字的决策链，而不仅仅是数字本身。

## 何时更新

该表反映已录入的结果和已生效的更正。一次结果更正会根据当前生效的事实重新计算整张表，绝不会手动调整数字。
