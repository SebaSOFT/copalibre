## 此界面的用途

在此管理组织的场地与裁判：赛程编排为某阶段的比赛分配的资源池。两者均可在该组织举办的每项赛事中重
复使用——创建一次，按需多次分配。

## 关键字段

- **场地名称/别名/容量**：场地的身份信息及其可同时容纳的比赛场数（拥有三片场地的俱乐部是容量为 3
  的一个场地，而非三个场地）。
- **场地详情**：供操作员阅读的自由文本——地址、场地类型，或对于虚拟场地（游戏服务器）而言，其地
  址、区域或当前地图。系统从不对其进行校验或解析。
- **裁判姓名/角色**：裁判的身份信息及其可被分配的角色（主裁判、助理裁判、记录台裁判、观察员）。

## 此界面无法进行的操作

暂不支持删除场地或裁判——因误操作创建且从未使用的记录可以直接忽略。将场地或裁判分配到某场具体比
赛的操作在赛程编排中完成，而非此处。
