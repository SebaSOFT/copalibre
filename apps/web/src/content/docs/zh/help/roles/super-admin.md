## 这个角色的用途

安装本身的操作者 —— 位于每个组织之上一层,不是任何组织的成员。超级管理员的存在是为了创建组织、管理还有谁拥有超级管理员权限、以及安装整个安装范围内运行的项目和赛事简介模块。

与本站的其他任何角色不同,超级管理员完全处于组织能力对应关系之外:它是一个安装级别角色
(`INSTALLATION_ROLES`),而不是组织角色(`ORGANIZATION_ROLES`),因此它在声明的角色到能力对应关系中没有条目,这里也不生成能力列表 —— 它的权限是一组固定且很小的安装级别操作,直接描述如下。

## 能做什么

- 创建一个新组织,命名其别名、显示名称、主要语言和时区,并在同一步骤中邀请其第一位管理员。
- 按主体 ID 列出、创建和移除安装级别的超级管理员。
- 按别名进入任意组织的用户列表,以更改某个用户的角色或状态 —— 而无需成为该组织的成员。
- 按别名安装项目或赛事简介模块,可选指定版本范围和备用来源;列出、验证、移除已安装的模块,并检查更新。
- 通过平台管理向导创建新的项目或赛事简介,生成一个模块包,随后由同一安装级别权限安装该模块包。

## 不能做什么

任何东西都触及不到某个组织自身的赛事数据:通过该角色看不到也编辑不了任何赛程、结果或报名信息。这些属于每个组织自己的控制面板,由某个 [admin](/zh/help/roles/admin/) 访问,而不是由超级管理员通过安装控制台访问。

## 能看到哪些界面

平台管理界面,以及没有任何其他控制面板界面 —— 限定于某个组织的界面属于组织角色,超级管理员并不仅凭超级管理员身份就拥有这些界面。
