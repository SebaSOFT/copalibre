## 概述

GSL 双败分组赛制（Bracket Groups）将选手分为4人一组的双败淘汰小组。两胜者晋级淘汰赛，两败者被淘汰出局。

## 小组比赛流程

1. **第一轮（首轮赛）**：
   - 比赛 1：1号种子 vs 4号种子
   - 比赛 2：2号种子 vs 3号种子
2. **第二轮（胜者赛与淘汰赛）**：
   - **胜者赛**：M1胜者 vs M2胜者。获胜方（2-0）以小组头名身份直接晋级。
   - **淘汰赛**：M1负者 vs M2负者。落败方（0-2）淘汰出局。
3. **第三轮（决定赛 / Decider）**：
   - 胜者赛负者 vs 淘汰赛胜者（战绩均为 1-1）。
   - 获胜方（2-1）以小组第二身份晋级，落败方淘汰出局。

## 多场次系列赛（BoN）

小组内的所有比赛均可设置为多场次决胜系列赛（如 Bo3 或 Bo5）。
