## Создание турнира

Выберите дисциплину, алиас турнира и заявленный формат. Алиас определяет публичный маршрут и
использует строчные буквы с дефисами.

## Проверка регистраций

Проверяйте участников перед их принятием. Каждое решение фиксирует автора и момент изменения.

## Публикация конфигурации

Опубликуйте проверенную конфигурацию перед созданием сетки. Последующие изменения классифицируются
по их влиянию на существующие результаты.

## Справка по экранам

У каждого экрана [панели управления](/ru/help/control/) есть своя страница справки, доступная по
ссылке «Что это за экран?» на боковой панели.
