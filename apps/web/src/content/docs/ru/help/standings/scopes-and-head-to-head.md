## Обзор

При равенстве очков CopaLibre применяет правила тай-брейка в различных областях оценки: по всем матчам (`overall`), только по личным встречам среди спорящих (`head-to-head`) или по матчам с поражениями. Множественные ничьи разрешаются рекурсивно.
