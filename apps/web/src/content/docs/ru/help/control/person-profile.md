## Назначение экрана

Показывает личность зарегистрированного человека: его фото (или заглушку, если ничего не загружено),
отображаемое имя, флаг гражданства и естественный ключ — тот же номер документа, по которому его
узнают в разных командах и соревнованиях. Открывается по ссылке «Просмотреть профиль» из развёрнутой
строки экрана проверки регистраций.

## Ключевые поля

- **Фото**: отображается, если оно было загружено через экран проверки регистраций; в противном
  случае вместо него рендерится силуэт-заглушка, а не битое изображение.
- **Гражданство**: флаг зафиксированного для человека кода страны ISO 3166-1 alpha-2, если он указан.
- **Естественный ключ**: удостоверяющий документ (например, номер национального удостоверения
  личности), зафиксированный для этого человека, если он существует.

## Чего этот экран НЕ делает

Он не позволяет ничего редактировать — гражданство и фото задаются из развёрнутой строки экрана
проверки регистраций, а не здесь. Отдельного экрана «редактировать человека» не существует.
