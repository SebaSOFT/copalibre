## Назначение экрана

Создаёт новый турнир внутри организации: выберите дисциплину, формат и базовые данные до того, как
будет зарегистрирован хотя бы один участник.

## Ключевые поля

- **Дисциплина**: набор правил вида спорта/деятельности, в которую будут играть (условие победы,
  очки, сегменты и т. д.). Отображаются только дисциплины, установленные на этой установке — если
  нужной нет, установите её сначала (`copalibre module add`), прежде чем сможете создать турнир.
- **Алиас**: идентификатор публичного маршрута турнира, уникальный в пределах организации.
  Использует строчные буквы и дефисы; отображается в публичном URL и не может быть свободно изменён
  впоследствии.
- **Формат**: формат соревнования, доступный для выбранной дисциплины (одиночное выбывание,
  круговая система и т. д.).

## Жизненный цикл

Новосозданный турнир начинается в состоянии **черновик**. Оттуда он следует по линейному пути:
черновик → опубликован → начат → завершён → архивирован. Каждый шаг — это явное решение на другом
экране, никогда не то, что этот экран делает за вас. После **начала** дисциплина и профиль турнира
фиксируются на версии, которую они имели в этот момент — идущий турнир никогда не меняет свои
правила на полпути.
