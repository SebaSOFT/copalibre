## Импорт

Участники массово импортируются через CSV с экрана
[проверки заявок](/help/control/registration-review). Каждая строка проверяется до записи чего-либо:
строка, не прошедшая проверку, сообщается с номером строки и причиной, и ни одна строка не
импортируется, пока весь файл не будет либо принят, либо исправлен и загружен заново — частично
импортированный файл не является состоянием, которое производит этот экран. CSV, ранее экспортированный
из этой же установки, импортируется обратно без проблем, так что цикл со списком участников
(отредактировать в таблице, вернуть обратно) — это поддерживаемый путь, а не случайность.

## Экспорт

- **Участники**: индивидуальные или командные составы, по алиасу — доступно с экрана
  [проверки заявок](/help/control/registration-review).
- **Результаты и турнирная таблица**: вычисленные результаты и таблица этапа, по алиасу — доступно с
  экрана [турнирной таблицы](/help/control/standings).
- **Конфигурация турнира**: полный регламент, переопределения и пользовательские скрипты в формате
  JSON, с панели организации — тот же документ, который новая установка могла бы импортировать обратно,
  чтобы воспроизвести правила турнира, но не его результаты.

Каждый экспорт заменяет внутренний идентификатор базы данных на публичный алиас сущности, поэтому
экспортированный файл никогда не раскрывает идентификатор, который не должен видеть никто вне
установки.

## Чего нельзя сделать на этом экране

Импорт результатов или турнирной таблицы не поддерживается — они вычисляются, а не вводятся, и
единственный способ изменить их постфактум — это
[аудируемый процесс исправления](/help/control/corrections).
