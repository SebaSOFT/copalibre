## Назначение экрана

Формирует жеребьёвку/сетку этапа: назначает каждому участнику начальную позицию («посев»), соблюдая
ограничения, заявленные для этой дисциплины/формата.

## Ключевые поля

- **Посев (seed)**: позиция посева участника в сетке — определяет, против кого он играет первым и в
  каком раунде может встретиться с другими высокими посевами.
- **Пропуск раунда (bye)**: когда количество участников не заполняет идеальную сетку, некоторые
  позиции «проходят раунд» без игры. Экран всегда распределяет их по одному и тому же правилу,
  никогда случайно.
- **Ограничения жеребьёвки**: заявленные правила (например, что два участника одного клуба не
  встречаются в первом раунде), которые жеребьёвка соблюдает автоматически — экран не позволяет
  сохранить жеребьёвку, нарушающую их.

## Когда её можно переделать

Жеребьёвку можно переделать, пока этап не начался. Как только этап идёт, переделывать жеребьёвку
уже не имело бы смысла при уже сыгранных матчах — экран не позволяет этого на данном этапе.
