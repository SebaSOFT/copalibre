## Для чего этот экран

Какой бы ни была структура этапа — одна группа, несколько зон, или серия из нескольких матчей — она
всегда сводится к списку матчей, которые предстоит сыграть. Этот экран — именно такой список, в виде
сетки карточек: весь турнир по умолчанию, либо ограниченный одним этапом, одной зоной/группой, или
одним статусом (в эфире, предстоящие, завершённые) с фильтрами сверху. Он дополняет, а не заменяет,
[турнирную сетку](/help/control/tournament-authoring) — сетка — правильное представление для просмотра
продвижения на выбывание; этот экран — правильное представление для быстрого просмотра большого
объёма, особенно среди нескольких одновременных круговых групп, которые сетка не может удобно показать
все сразу.

Этот экран существует в двух версиях, использующих одну и ту же карточку:

- **Публичная** (`/{организация}/tournaments/{турнир}/matches`) — анонимная, вход не требуется.
- **Панель управления** (`.../matches-view`) — доступна только администратору организации или
  tournament-admin с полномочиями на этот турнир — те же полномочия, которые уже требует экран
  внутренней турнирной таблицы.

## Что показывает каждая карточка

- **Статус**: в эфире, предстоящий или завершённый, вместе со значком, чтобы статус никогда не зависел
  только от цвета.
- **Таймер**: показывается только пока матч идёт — текущее прошедшее время, то же значение, которое
  читает консоль матча в реальном времени.
- **Площадка**: название назначенной площадки, если расписание уже её назначило.
- **Последнее событие**: последнее зафиксированное событие, каким бы оно ни было — эта карточка никогда
  не обрабатывает конкретный тип события как особый случай, поэтому дисциплина, объявляющая новое
  событие (подтверждение после видеопросмотра, замена), корректно отображается без каких-либо изменений
  на этом экране.
- **Зона/позиция или статус серии** — никогда оба сразу на одной карточке:
  - Пара в этапе с зонами/группами без объявленной серии показывает название зоны/группы (когда этап
    объявляет больше одной группы по умолчанию) и текущую позицию каждого участника в турнирной
    таблице.
  - Пара, решённая серией, показывает её прогресс, а после завершения — итоговый счёт по сумме — то же
    представление серии, которое уже использует
    [публичная турнирная сетка](/help/control/series).
- **Решающий фактор**: на завершённом матче, результат которого потребовал компаратора тай-брейка для
  разделения двух строк турнирной таблицы, — строка, называющая, что стало решающим (например,
  «решено по разнице мячей в личных встречах»).

## Строка решающего фактора против полной трассировки

Строка решающего фактора на публичной карточке — намеренно краткое резюме, а не полное обоснование —
она никогда не содержит остальных шагов или промежуточных значений внутреннего компаратора.
Организатор с полномочиями на внутреннюю турнирную таблицу этого турнира (администратор, или
tournament-admin с полномочиями на него) вместо этого видит полную трассировку компаратора — в версии
той же карточки в панели управления, точно так же, как её уже показывает раскрывающаяся трассировка на
экране внутренней турнирной таблицы. Никто не видит промежуточную версию: зритель видит либо краткое
резюме в одну строку, либо полную трассировку, но никогда частично скрытую версию.

## Чего этот экран НЕ делает

Он предназначен только для просмотра. Ни одна карточка и ни один элемент управления здесь не меняют
статус матча, не фиксируют событие и не редактируют расписание — эти действия остаются на
[консоли матча в реальном времени](/help/control/match-console) и в
[конструкторе расписания](/help/control/schedule). Этот экран нужен для того, чтобы видеть, что
происходит и что уже произошло, а не для управления матчем.
