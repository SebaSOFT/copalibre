## Назначение экрана

Показывает каждый заявленный турниром этап — его номер, название, формат и был ли уже проведён
посев. Выбор этапа открывает центр этого этапа, где находятся его идентичность, посев, а также
инструменты зон, турнирной таблицы и расписания.

## Ключевые поля

- **Этап**: часть турнира (например, «Групповой этап» или «Плей-офф») — турнир может заявить
  несколько, по порядку.
- **С посевом**: показывает, есть ли у этапа уже сформированный матч. Этап без посева всё ещё
  можно переименовать, изменить формат или удалить; уже посеянный этап можно только переименовать.

## Как попасть на этот экран

Откройте его через действие «Этапы» на карточке турнира на панели организации, либо перейдя
напрямую по собственному URL управления турниром.
