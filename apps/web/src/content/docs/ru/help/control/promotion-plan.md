## Назначение экрана

Как только группы зоны завершают свой круговой этап, этот экран настраивает, сколько участников
проходит из каждой группы и как эти группы объединяются в один упорядоченный список для следующего
этапа. Затем он показывает этот вычисленный упорядоченный список для проверки — он никогда сам по
себе не создаёт и не изменяет посев.

## Ключевые поля

- **Количество участников, проходящих из каждой группы**: сколько участников из каждой группы
  повышается.
- **Полосы**: когда на следующем этапе несколько зон, какой непрерывный отрезок объединённого списка
  направляется в какую из зон этого этапа.
- **Проверка**: упорядоченный список кандидатов, который повысил бы этот план, вычисляемый всегда
  одинаково — ничего не записывается на следующий этап, пока оператор явно не настроит его посев в
  конструкторе посева, который предзаполняется из проверенного плана, если он существует.

## Чего нельзя сделать на этом экране

Если в группе есть неразрешённая ничья на её собственной линии отсечения, этот экран сообщает об
этом, а не показывает неполный список — разрешите ничью (фиксируемое исправление, если исходный
результат в нём нуждается), прежде чем можно будет вычислить объединённый список.
