## Назначение экрана

Экран настроек позволяет управлять вашими личными настройками в CopaLibre.

## Персональные токены доступа

Вы можете создавать персональные токены доступа (PAT) для аутентификации в API или MCP-сервере
CopaLibre без использования имени пользователя и пароля.

- **Создать токен**: введите метку и срок действия, затем нажмите «Создать». Обязательно скопируйте
  токен сразу же — повторно его посмотреть будет нельзя.
- **Отозвать токен**: если токен скомпрометирован или больше не нужен, вы можете отозвать его в любой
  момент.

Эти токены не хранят состояние и подтверждают вашу личность при каждом запросе.
