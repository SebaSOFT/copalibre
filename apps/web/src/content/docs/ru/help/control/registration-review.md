## Назначение экрана

Проверяет каждого зарегистрированного участника или команду перед публикацией турнира и решает,
будет ли каждый из них принят, отклонён или отозван. Каждое решение фиксируется отдельно, с
предыдущим состоянием, результирующим состоянием и тем, кто его принял.

## Ключевые поля

- **Статус**: ожидает, принят, отклонён или отозван. С каждого статуса разрешены только допустимые
  переходы — экран не позволяет применить недопустимое решение (например, принять то, что уже
  отклонено).
- **Импорт из CSV**: загрузите файл участников; система проверяет содержимое и показывает
  построчный предпросмотр перед подтверждением. Ни одна строка с ошибкой не импортируется, пока
  файл не будет исправлен и повторно загружен.
- **Участники, которым нужна аббревиатура**: участник, конфликтующий по каждой автоматически
  выведенной короткой метке, регистрируется без установленной метки и иначе остаётся невидимым — этот
  раздел перечисляет таких участников и позволяет задать метку напрямую. Значение, уже используемое
  другим участником турнира, отклоняется на месте с указанием конфликта; разрешённый участник исчезает
  из списка.
- **Массовая проверка**: применяет одно и то же решение к нескольким регистрациям одновременно;
  каждая всё равно фиксируется отдельно, а не как единое агрегированное событие.

## Чего этот экран НЕ делает

Он не изменяет результаты матчей или сетку — он касается исключительно того, кто участвует, до
начала турнира.
