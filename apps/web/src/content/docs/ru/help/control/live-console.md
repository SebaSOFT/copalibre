# Консоль в реальном времени

## Назначение этого экрана

Быстрый доступ к активным турнирам и управлению матчами в режиме реального времени.

## Сегменты

Матч играется по сегментам: таймам, сетам или периодам. «Запустить» создаёт регламентные сегменты, предусмотренные регламентом матча, например два тайма футбольного матча или сеты, необходимые для решения матча до трёх побед, и запускает первый. «Пауза» и «Завершить период» действуют на текущий сегмент.

«Добавить сегмент» добавляет ещё один сегмент любого типа, предусмотренного дисциплиной, например дополнительное время, серию пенальти или решающий сет. Сегмент сверх регламентного плана принимается и помечается «(вне плана)»: что играется сверх регламента, решает организатор.

Начатый матч без сегментов тоже можно вести: выберите тип в «Добавить сегмент» и продолжите матч с нового сегмента.
