## Назначение экрана

Показывает обращения и споры, которые сами участники отправили по поводу матча (например,
«загруженный результат не соответствует тому, что мы сыграли», с приложенными доказательствами),
чтобы организатор мог их рассмотреть и решить, что делать.

## Ключевые поля

- **Обращение** против **спора**: обращение — это заявление участника о произошедшем; спор
  конкретно оспаривает уже загруженный результат.
- **Доказательства**: вложения (изображение, видео, PDF), которые участник загрузил в качестве
  подтверждения. Они проходят асинхронную проверку содержимого/вредоносного ПО, прежде чем
  считаться действительными — вложение, помеченное как небезопасное, никогда не отображается как
  действительное ни одному проверяющему.
- **Статус проверки**: ожидает, проверено или отклонено, с примечанием проверяющего.

## Чего этот экран НЕ делает

Проверка обращения **никогда** не перезаписывает результат напрямую. Уже загруженный результат
меняется только через фиксируемый путь исправления/замены (причина, предыдущее состояние,
результирующее состояние, предварительный просмотр пересчёта) — этот экран предназначен для того,
чтобы организатор решил, _оправдано ли_ такое исправление, а не для самого исправления.
