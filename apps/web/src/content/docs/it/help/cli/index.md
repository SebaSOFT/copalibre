---
title: Il CLI copalibre
description: Installazione, aggiornamento e riferimento dei comandi del CLI copalibre.
---

Il CLI `copalibre` gestisce un'installazione autogestita: installa, valida la configurazione, avvia
i processi, gestisce i moduli e esegue backup/ripristino dei dati. Ogni invocazione accetta
`--help`/`-h` — sia senza comando (`copalibre --help`) che dopo qualsiasi comando (`copalibre doctor
--help`) — per mostrare il suo uso esatto senza eseguire alcun effetto reale.
