Die Befugnis jeder Rolle stammt aus einer einzigen deklarierten Zuordnung, nicht aus dem Lesen jedes
Bildschirms und jeder Route, die sie erwähnt. Dieser Abschnitt hat eine Seite pro Rolle, die jeweils
angibt, was diese Rolle tun kann (direkt aus der Zuordnung generiert, sodass es niemals stillschweigend
von dem abweichen kann, was tatsächlich durchgesetzt wird), was sie erbt und von welcher Rolle, was sie
bemerkenswerterweise nicht kann, und welche Bildschirme des Kontrollpanels sie sieht.

- [Vereinsadmin](/de/help/roles/club-admin/)

- [Super-Admin](/de/help/roles/super-admin/)

Admin, Vereinsadmin, Turnieradmin, Schiedsrichter, Übertragung und Viewer sind Organisationsrollen —
gehalten innerhalb einer Organisation, und ohne Bedeutung außerhalb davon. Super-Admin ist anders: eine
Rolle auf Installationsebene, eine Ebene über jeder Organisation, auf ihrer eigenen Seite beschrieben.
