## Wofür dieser Bildschirm ist

Die Vereine einer Organisation werden hier verwaltet: Erstellen Sie einen, bearbeiten Sie seinen
Namen/Alias/Abkürzung, und laden Sie sein Wappen hoch oder ersetzen Sie es. Das Wappen eines Vereins wird
überall dort angezeigt, wo der Verein erscheint — seine Teilnehmerlisten, das Raster der öffentlichen
Organisationsseite — mit einem Platzhalter, bis eines hochgeladen wurde.

## Wichtige Felder

- **Name**: der vollständige Name des Vereins.
- **Alias**: eine URL-taugliche Kennung, eindeutig innerhalb der Organisation. Wird beim Erstellen aus
  dem Namen vorgeschlagen, wenn das Feld leer bleibt.
- **Abkürzung**: eine kurze Bezeichnung, die auf Flächen mit begrenztem Platz angezeigt wird (z. B. einer
  Anzeigetafel).
- **Wappen**: ein über diesen Bildschirm hochgeladenes Bild, das ein vorheriges ersetzt.

## Was Sie hier nicht tun können

Die Mannschaften eines Vereins und ihre Kader werden an anderer Stelle verwaltet — dieser Bildschirm
verwaltet nur die eigenen Identitätsfelder und das Bild des Vereins.
