# Live-Konsole

## Zweck dieses Bildschirms

Schneller Zugriff auf aktive Turniere und Echtzeitoperationen laufender Partien.

## Segmente

Ein Spiel wird in Segmenten gespielt: Halbzeiten, Sätzen oder Abschnitten. „Starten“ erstellt die Regelsegmente, die das Regelwerk des Spiels vorsieht, etwa die zwei Halbzeiten eines Fußballspiels oder die Sätze, die ein Best-of-Three-Spiel entscheiden, und setzt das erste in Gang. „Pausieren“ und „Abschnitt beenden“ wirken auf das laufende Segment.

„Segment hinzufügen“ hängt ein weiteres Segment eines Typs an, den die Disziplin vorsieht, etwa Verlängerung, Elfmeterschießen oder einen entscheidenden Satz. Ein Segment über den Regelplan hinaus wird angenommen und mit „(außerhalb des Plans)“ gekennzeichnet: Was über die Regelzeit hinaus gespielt wird, entscheidet der Veranstalter.

Ein Spiel, das gestartet wurde, aber keine Segmente zeigt, kann weiter geführt werden: Wählen Sie unter „Segment hinzufügen“ einen Typ und setzen Sie das Spiel mit dem neuen Segment fort.
