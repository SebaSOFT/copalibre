## Wofür dieser Bildschirm ist

Listet jede vom Turnier deklarierte Phase auf — ihre Nummer, ihren Namen, ihr Format und ob sie
bereits ausgelost wurde. Die Auswahl einer Phase öffnet das Zentrum dieser Phase, in dem ihre
Identität, ihre Auslosung und ihre Werkzeuge für Zonen, Tabelle und Spielplan liegen.

## Wichtige Felder

- **Phase**: ein Abschnitt des Turniers (zum Beispiel „Gruppenphase" oder „Playoffs") — ein
  Turnier kann mehrere davon deklarieren, in Reihenfolge.
- **Ausgelost**: ob die Phase bereits ein erzeugtes Spiel enthält. Eine nicht ausgeloste Phase
  kann noch umbenannt, umformatiert oder entfernt werden; eine bereits ausgeloste Phase kann nur
  umbenannt werden.

## So erreichen Sie diesen Bildschirm

Öffnen Sie ihn über die Aktion „Phasen" auf der Karte eines Turniers im Dashboard der
Organisation, oder indem Sie direkt zur eigenen Steuerungs-URL des Turniers navigieren.
