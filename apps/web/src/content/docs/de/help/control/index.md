title: Kontrollpanel
description: Wofür jeder Bildschirm im CopaLibre-Kontrollpanel ist.
---

Jeder Bildschirm im Kontrollpanel hat einen Link „Was ist dieser Bildschirm?“ in seiner
Seitenleiste, der direkt zur entsprechenden Seite in diesem Abschnitt führt. Diese Seite listet sie
alle auf.

- [Turniererstellung](/help/control/tournament-authoring/)
- [Anmeldungsprüfung](/help/control/registration-review/)
- [Melde- und Streitfallprüfung](/help/control/report-review/)
- [Tabelle](/help/control/standings/)
- [Auslosung und Setzung](/help/control/seeding/)
- [Rollen und Berechtigungen](/help/control/roles-permissions/)
- [Live-Spielkonsole](/help/control/match-console/)

Für Installation, Aktualisierung oder das Verständnis der Administrations-CLI-Befehle siehe die
[CLI-Dokumentation](/help/cli/).
