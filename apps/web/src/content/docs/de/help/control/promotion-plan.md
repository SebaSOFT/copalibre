title: Aufstiegsplan
description: Konfigurieren, wie sich die Gruppen einer Zone zur Setzung der nächsten Phase kombinieren — vor der Anwendung überprüft.
---

## Wofür dieser Bildschirm ist

Sobald die Gruppen einer Zone ihre Rundenspiele beendet haben, konfiguriert dieser Bildschirm, wie
viele Teilnehmer aus jeder Gruppe aufsteigen und wie sich diese Gruppen zu einer geordneten Liste für
die nächste Phase kombinieren. Anschließend zeigt er diese berechnete, geordnete Liste zur Überprüfung
an — er erstellt oder ändert von sich aus nie eine Setzung.

## Wichtige Felder

- **Aufsteigende Teilnehmer pro Gruppe**: wie viele Teilnehmer aus jeder Gruppe aufsteigen.
- **Bänder**: wenn die nächste Phase mehr als eine Zone hat, welcher zusammenhängende Abschnitt der
  kombinierten Liste zu welcher Zone dieser Phase geleitet wird.
- **Überprüfung**: die geordnete Kandidatenliste, die dieser Plan befördern würde, jedes Mal auf
  dieselbe Weise berechnet — nichts wird in die nächste Phase geschrieben, bis ein Bediener seine
  Setzung explizit über den Setzlisten-Editor konfiguriert, der sich aus einem geprüften Plan
  vorausfüllt, sofern einer existiert.

## Was Sie hier nicht tun können

Wenn eine Gruppe an ihrer eigenen Schnittlinie ein ungelöstes Unentschieden hat, meldet dieser
Bildschirm das, statt eine unvollständige Liste zu zeigen — lösen Sie das Unentschieden auf (eine
protokollierte Korrektur, falls das Ausgangsergebnis eine benötigt), bevor eine kombinierte Liste
berechnet werden kann.
