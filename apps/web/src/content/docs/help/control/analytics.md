# Analytics

The Analytics screen displays high-level key performance indicators (KPIs) and operational volume metrics for the organization.

## Key Metrics

- **Total Tournaments**: Active, upcoming, and completed tournament counts.
- **Storage Consumption**: Total bytes and media asset counts stored across tournaments.

## Tournament Overview

The overview lists each non-archived tournament with its lifecycle status, resolved matches out of the total, and live match count. Match progress may be unavailable for an individual tournament while leaving the rest of the dashboard visible.
