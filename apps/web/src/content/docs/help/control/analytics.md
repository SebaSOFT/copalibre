# Analytics

The Analytics screen displays high-level key performance indicators (KPIs) and operational volume metrics for the organization.

## Key Metrics

- **Total Tournaments**: Active, upcoming, and completed tournament counts.
- **Storage Consumption**: Total bytes and media asset counts stored across tournaments.
