## What this screen is for

Shows one stage's number, current name and format, and is where that stage is renamed, has its
format changed, or is removed. It also links to that same stage's seeding, zones-and-groups,
standings and schedule screens, and each of those links back here.

## Key fields

- **Rename**: always available, whether or not the stage has been seeded.
- **Change format**: available only while the stage holds no generated fixture. Once seeded, the
  screen names why the action is locked instead of only refusing it silently.
- **Delete stage**: available only while the stage holds no generated fixture, and only while no
  promotion plan already targets it.

## Reaching this screen

Open it from a tournament's stage list, or from the breadcrumb link on that stage's seeding,
zones-and-groups, standings or schedule screen.
