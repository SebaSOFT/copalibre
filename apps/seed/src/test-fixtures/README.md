# Test fixtures

`rink-hockey-1.1.0.artifact.json` is a verbatim copy of `disciplines/rink-hockey/artifact.json` (version 1.1.0, AGPL-3.0-only)
from the CopaLibre modules repository. The demo-dataset loader requires the `rink-hockey` discipline to be installed, and the
default catalogue does not ship it, so the loader's integration tests install this copy. Refresh it when the dataset's
discipline version moves.
